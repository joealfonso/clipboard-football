## How to read this

- Cache: raw downloads live in `~/.cache/clipboard-football`, or the directory named by `CLIPBOARD_FOOTBALL_CACHE`. Delete the directory to refresh everything.
- Seasons requested run from each loader's documented first season to the last season nflreadpy allows on the run date.
- Null %: percent of rows that are null, two decimals. Overall rates count only the seasons where the column exists. `-` means the column is absent that season; `n/a` means zero rows.
- Per-season null rates are shown for play-by-play, participation and FTN charting only. Other tables show overall rates.
- License: nflreadpy does not expose license or source terms per table. Findings checked by hand are in the Licenses section below; other tables are unchecked.
- Only counts and column metadata appear here. No player names or IDs.
